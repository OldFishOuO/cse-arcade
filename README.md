# CSE ARCADE — 資工系遊戲攤

七款資工系主題小遊戲組成的單頁網站，專門為**學校活動擺攤**設計：完全離線、不需安裝、不需網路、不需登入。

---

## 一、怎麼打開（三種方式，挑一種）

### ① 攤位現場最保險 — 單檔版
雙擊 **`cse-arcade-standalone.html`**。

一個檔案就是整個網站（180 KB），CSS 和 12 個 JS 全部內嵌，**零外部相依**。
可以丟 USB、用 LINE 傳、寄 email、放在任何電腦上雙擊 —— 不會因為少了 `assets/` 資料夾而壞掉。
不需要 Python、不需要網路、不需要安裝任何東西。

> 改過原始碼之後要重新產生：`python build-single-file.py`

### ② 要改東西時 — 本機伺服器
雙擊 **`啟動攤位伺服器.bat`**（Windows），它會自動開啟瀏覽器。
或自己下指令：

```bash
python -m http.server 8765
```

然後打開 <http://localhost:8765>。
改完 `config.js` 重新整理就看得到，不用重新打包。

### ③ 直接雙擊 `index.html`
也可以跑。程式刻意**沒有用 ES module、沒有 build 步驟、沒有任何 CDN**，
所以 `file://` 不會有 CORS 問題。
唯一的差別：少數瀏覽器在 `file://` 下會禁止 localStorage，
這時排行榜不會保存（網站仍可正常玩，「攤位設定」頁會顯示黃色警告）。
**攤位現場請用 ① 或 ②。**

## ⚠ 如果你看到「沒有樣式的純文字頁面」

那不是程式壞了，是**開啟方式**的問題。

| 現象 | 原因 | 解法 |
|---|---|---|
| 在 Claude / VS Code / 其他工具的「預覽視窗」裡看起來像沒排版的純文字 | 這些預覽視窗會把本機 HTML 轉成 `data:` 網址的靜態快照，**相對路徑無法解析、`<script>` 也會被擋掉**，所以 CSS 和 JS 全部載入失敗 | 改用 ① 單檔版，或 ② 本機伺服器，或直接在 Chrome / Edge 裡開 |
| 搬動檔案後打不開 | `index.html` 需要旁邊的 `assets/` 資料夾 | 要整個資料夾一起搬；只想搬一個檔就用 ① 單檔版 |
| 分數重新整理就消失 | 瀏覽器禁止了 localStorage（無痕模式 / `file://` 限制） | 改用 ② 本機伺服器 |

快速自我檢查：打開網頁後按 **F12** → Console，如果看到一堆
`Failed to load resource: assets/js/...`，就是上面第一種狀況。

## 二、七款遊戲在教什麼

| # | 遊戲 | 一局 | 教的概念 | 適合誰 |
|---|------|------|----------|--------|
| 1 | **資工系大誤解** | 10 題 | 破解對資工系的迷思（課程、出路、數學） | 所有人，當開場 |
| 2 | **二進位快打** | 60 秒 | 位元、位值、1 byte = 8 bits | 國高中生都能玩 |
| 3 | **Bug 獵人** | 165 秒 | 常見程式錯誤：off-by-one、`=` vs `==`、無限迴圈… | 沒寫過程式也看得懂 |
| 4 | **邏輯閘實驗室** | 160 秒 | AND / OR / NOT / XOR / NAND、真值表、電路設計 | 愛解謎的人 |
| 5 | **排序大師** | 150 秒 | 排序、置換環（最少交換次數 = n − 環數） | 喜歡動腦的人 |
| 6 | **封包路由** | 150 秒 | 網路拓撲、最短路徑（Dijkstra）、ping 的延遲 | 視覺型玩家 |
| 7 | **終端機打字** | 50 秒 | 常用指令在做什麼（ls / git / ssh / ping…） | 手快的人，回鍋率最高 |

每款遊戲結束後都會跳出**小知識卡**——這才是整個攤位真正的教育目的，
遊戲只是把人留住的手段。

## 三、要改成你們系的資訊

**只要改一個檔案：`assets/js/config.js`**

```js
CSE.config = {
  title:   'CSE ARCADE',        // 攤位代號
  school:  '○○大學',            // ← 改這裡
  dept:    '資訊工程系',         // ← 改這裡
  booth:   '資工系遊戲攤',
  tagline: '七款小遊戲，10 分鐘看懂資工系在學什麼',

  prize: {
    enabled: true,
    threshold: 3000,            // ← 兌換小禮物的總分門檻
    text: '總分達 3000 分，拿給攤位人員看就能兌換小禮物'
  },

  links: { ig: '', web: '', line: '' },   // ← 填了才會顯示按鈕

  about: { … }                  // ←「關於資工系」整頁的內容都在這裡
};
```

其他可以改的內容：

| 想改什麼 | 改哪個檔 |
|----------|----------|
| 「資工系大誤解」的題目 | `assets/js/games/myth.js` 最上面的 `Q` 陣列 |
| Bug 獵人的程式碼片段 | `assets/js/games/bughunt.js` 最上面的 `SNIPPETS` |
| 打字遊戲的指令清單 | `assets/js/games/typing.js` 最上面的 `CMDS` |
| 邏輯閘的關卡 | `assets/js/games/logic.js` 的 `LEVELS` |
| 獎牌門檻 / 稱號 | 各遊戲檔案裡的 `medals` 和 `titles` |
| 配色、字體、版面 | `assets/css/main.css` 最上面的 `:root` 變數 |

> **總分 = 七款遊戲各自的「最佳分數」加總**（不是累加每一局）。
> 這樣設計是為了鼓勵訪客七款都玩一次，而不是在同一款狂刷。

## 四、擺攤當天的操作

1. 打開網站 → 右上角 **⛶** 或鍵盤 **F11** 進入全螢幕（訪客就不會誤觸網址列）。
2. 進「**攤位設定**」頁：
   - **攤位模式**打開 → 沒人操作 75 秒後自動回首頁並顯示「點一下開始」。
     平板放著自己跑也不會卡在別人的結算畫面。
   - 攤位很吵 → 關掉**音效**。
   - 舊筆電會頓 → 關掉**背景動畫**。
3. 訪客玩完可以輸入暱稱上排行榜（最多 10 個字，會擋空白與基本不雅字）。
4. **活動結束前，一定要先到「攤位設定」按「匯出排行榜 CSV」**，
   否則清除資料後就救不回來了。CSV 有 BOM，可以直接用 Excel 開啟。

### 多台裝置
每台裝置的排行榜是**各自獨立**的（資料存在該台瀏覽器的 localStorage，不會上傳）。
要合併就各自匯出 CSV 再用 Excel 合併。

### 想讓訪客用自己的手機玩
把整個資料夾推上 GitHub Pages / Netlify / Cloudflare Pages（純靜態，丟上去就好），
再用任何線上 QR 產生器把網址做成 QR code 貼在攤位上。
手機版排行榜會是訪客自己手機上的，攤位的主排行榜還是以現場那台為準。

## 五、檔案結構

```
cse-arcade-standalone.html  ★ 單檔版（打包產物）— 攤位現場用這個
啟動攤位伺服器.bat           ★ Windows 一鍵啟動本機伺服器
build-single-file.py        把下面的原始碼打包成單檔版

index.html                  原始入口，所有 <script> 都在這裡
assets/
  css/main.css              全站樣式（終端機 / CRT 風格）
  js/
    config.js               ★ 攤位設定，改這個就好
    core.js                 DOM 工具、儲存、設定、音效、Modal、遊戲註冊表
    scores.js               排行榜、個人最佳、徽章、CSV 匯出
    host.js                 遊戲外框：準備畫面 / 計時 / 計分 / 結算 / 資源回收
    app.js                  路由、首頁、排行榜、關於、設定、背景特效、攤位模式
    games/*.js              七款遊戲，一款一個檔
.claude/launch.json         本機開發伺服器設定
```

> **改東西的流程**：改 `assets/` 底下的原始碼 → 用方式 ② 預覽確認 →
> 跑 `python build-single-file.py` 重新產生單檔版 → 把單檔版帶去攤位。
> 不要直接改 `cse-arcade-standalone.html`，下次打包會被蓋掉。

### 想自己加第八款遊戲

1. 在 `assets/js/games/` 新增一個檔。
2. 照這個樣板寫：

```js
CSE.registerGame({
  id: 'mygame',
  name: '我的遊戲',
  tag: '分類 · TAG',
  icon: '#',
  accent: 'var(--cyan)',
  blurb: '首頁卡片上的一句話介紹。',
  how: ['玩法第一點', '玩法第二點'],
  duration: 60,                                   // 0 = 不用全域倒數
  medals: { bronze: 500, silver: 1000, gold: 1600 },
  titles: ['體驗組', '新手', '高手', '大神'],
  knowledge: { title: '小知識標題', lines: ['第一行', '第二行'] },

  mount: function (stage, api) {
    // stage 是可以隨便塞 DOM 的容器
    // api.addScore(n) / api.hint(字串, 'good'|'bad') / api.setStat(標籤, 值)
    // api.on(目標, 事件, fn)  → 離開時自動解除監聽
    // api.after(ms, fn) / api.every(ms, fn) → 自動清掉
    // api.finish({ reason:'cleared', stats:[{k:'答對',v:'5 題'}] })
    // api.onResult(fn) → 時間到時 host 會呼叫，用來補結算統計

    return {
      onFrame: function (dt) { /* 每一幀，dt 是秒 */ }
    };
  }
});
```

3. 在 `index.html` 加一行 `<script src="assets/js/games/mygame.js"></script>`
   （要放在 `app.js` 之前）。
4. 在 `assets/js/app.js` 的 `ORDER` 陣列裡加上 `'mygame'` 決定首頁排序。

`host.js` 會自動處理準備畫面、倒數、分數、結算、排行榜登錄與資源回收，
所以新遊戲只要專心寫玩法本身。

## 六、設計上刻意做的幾個決定

| 決定 | 原因 |
|------|------|
| 不用 ES module / 不用框架 / 不用 CDN | 活動現場網路常常不能用，而且要能雙擊 `index.html` 就開 |
| 每款遊戲 50–165 秒 | 攤位會排隊，一個人卡太久後面的人就走了 |
| 先玩、後教 | 開頭塞教學沒人看；小知識卡放在結算畫面，這時候人才會看 |
| 倒數用 `requestAnimationFrame` 而不是 `setInterval` | 切到別的分頁會自動暫停，回來也不會瞬間扣光時間 |
| 計時 delta 夾在 0.1 秒 | 舊電腦掉幀時不會一次扣掉好幾秒 |
| localStorage 存不了就自動退回記憶體 | 無痕模式 / `file://` 限制下不會整站壞掉，只會提示資料不會保留 |
| 對錯同時用顏色**和**符號（✓ / ✕ / ♥） | 色覺不同的人也分得出來 |
| 結算畫面蓋上後底下元件設為 `inert` | 避免用 Tab 鍵還能點到背後的按鈕 |

## 七、已知限制

- 排行榜是**單機**的，沒有伺服器。要跨裝置即時排行就需要後端，目前刻意不做（攤位用不到，而且會變成網路故障點）。
- 終端機打字遊戲需要**英數輸入法**。偵測到中文輸入法會跳提示，但沒辦法自動切換。
- 手機玩打字遊戲會跳出虛擬鍵盤，體驗一般；其他六款都是純點擊，手機完全沒問題。
- 沒有做暗色 / 亮色切換 —— 整個視覺就是終端機風格，只有暗色。
